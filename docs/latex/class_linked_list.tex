\doxysubsection{Detailed Description}
Klasa implementująca dynamiczną listę dwukierunkową w języku C++. 

Klasa zarządza węzłami typu \doxylink{class_node}{Node}, umożliwiając efektywne operacje dodawania, usuwania oraz przeglądania elementów zarówno w przód, jak i w tył.
